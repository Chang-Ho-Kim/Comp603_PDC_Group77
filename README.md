# SmartHome Simulator 

This is a Java project built with Apache NetBeans IDE 28 (JDK 25) using Ant.

## Description

A smart home simulation where you can:
- Manage devices in the system  
- Manage automation for each device  
- Get electricity usage rate and billing  
- View logs and more
